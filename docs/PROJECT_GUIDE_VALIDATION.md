# Project Guide 验证记录

日期：2026-11-11。对应 [project-guide skill](skills/project-guide/SKILL.md) 与 [独立提示词](PROJECT_GUIDE_PROMPT.md)，协议为 `project-guide-v1`。

本轮验证的是“AI 依据文件生成新人导览”的方法与 skill 包，未把它接入 DevMate 页面。外部参考产品只查阅了资料，没有安装或运行。

## 1. 验证方法

在仓库外创建小型合成项目，由独立 Agent 读取 skill 和原始项目完成正常导览请求。未向它们提供预期结论、疑似错误或本验收清单，未让它们评价或修改 skill。主 Agent 再对照原始文件、实际输出及所报告的读取命令核对。

目标代码不运行，依赖不安装，数据库不访问；输出只写临时验收目录。隔离样例没有真实业务凭据。可见文件完整读取仅针对这些小型样例，不能推广为真实大仓库的覆盖率。

## 3. 发现的问题与修正

首版购物导览虽然先给了简明介绍，仍主动继续展开金额计算、结算返回字段及连接器细节。内容有源码依据，但默认阅读负担不符合用户“先看懂，想深入再自己深入”的目标。

据此只收紧展示时机：

- 默认只交付第一层；第二、三层等用户选择模块、追问或明确要求完整报告后再展开。
- 保存 Markdown 时允许折叠附上证据和覆盖范围；没有折叠能力时给简短范围说明与深入入口。
- 验收操作日志另外报告，不写入新人导览正文。

对应修改已同步到 skill、输出约定和独立提示词。复验仍使用原始购物工作区及新人请求，由新的独立 Agent 完成，不提供首版输出或预期答案。

复验结果：`checkout-guide-revised.md` 的默认正文止于项目用途、三项能力、两条主流程、必要边界和可继续了解的主题；没有主动展开逐步技术讲解，实际证据与覆盖说明位于折叠区。模拟结算、未接通的连接器及 README 冲突仍被识别，操作命令另外交付。主 Agent 已回读全文并对照先前原始文件核对。本次修正解决了已观察到的默认展开问题，尚不能替代真实新人的可读性测试。
