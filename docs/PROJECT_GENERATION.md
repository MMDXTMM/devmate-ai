# 多语言项目生成：当前实现

2026-11-13，按用户要求恢复生成路线。沿用Spring Boot + Vue模块化单体、MySQL和账户模型连接；被生成项目的语言由用户选择，不受宿主Java技术栈限制。

## 使用流程

1. 左侧“生成新项目”，用一句话说明做什么；先确认用途、使用者、界面与第一版核心功能。
2. AI依据需求给语言选择题，解释学习成本与适用场景。
3. 依照选定语言推荐兼容框架、架构和必要的界面方案。
4. 补齐数据存储、运行方式和其他影响交付的选择。每题2～4项，显示推荐理由、选项影响，可采用推荐、由AI决定或自由补充。
5. AI结合全部回答整理最终方案；有冲突再追问，无关键缺口时允许确认。最多8次追问提交，每次保留不可变版本。
6. 确认后显式“生成项目源码”，后台调用模型，成功后预览文件、查看运行说明、下载ZIP。可从最近20条历史继续会话；读取历史与刷新不调用模型。

现代运行使用真实Spring AI结构化输出；测试Profile中的guided-requirement-v2仅用于历史兼容回归，不作为线上智能生成。当前Prompt为project-builder-v1，问题与源码提示词分别版本化在resources/prompts。

## 权限、状态与预算

- 用户只能操作自己的会话，生成绑定confirmed_version_id；未确认、版本过期和处理中拒绝生成或修改。
- 追问模型前CAS切THINKING，成功短事务保存新版本并回CLARIFYING；失败保留旧版本并写可读lastError。初始描述失败时返回错误，不伪造会话或选择题。
- 生成采用2个工作线程、2项排队。唯一version_id约束，同版本进行中/已成功直接返回已有任务。显式失败用新attemptKey重试；网络结果不确定时沿用原键。
- 线程捕获当前账户的受信任模型快照；连接5秒、读取180秒，无自动付费重试。查询将超过10分钟的THINKING/RUNNING转为可重试状态。
- 最多60个模型文件、单文件50000字符、总计180000字符；必须有README.md和实际源码。服务端拒绝重复路径、越界路径、绝对路径、秘密文件、依赖/构建目录和符号链接。最终说明DEVMATE_GENERATION.md由服务器写入。
- 生成目录位于workspace/generated，独立于导入项目。ZIP与文件读取必须属于成功任务清单；前端将源码作为文本呈现，不执行HTML或脚本。所有生成输出均不得包含真实Key。

## 实际交付与边界

交付真实文本源码、依赖或环境说明、业务实现、README和测试文件（由模型按方案生成），并提供ZIP与预览。初次生成只验证文件结构、路径、大小和基本交付物，generation_run.verification=STRUCTURE_ONLY。2026-11-14 起，生成成功后可打开“验证与修复”，为不可变源码版本单独创建真实容器验证记录。支持无外部依赖的 Python unittest、Node 原生 JS 测试、Java 源码编译；Java 编译成功不会显示测试通过。外部依赖、没有测试或不支持的栈显示 BLOCKED 和原因；不自动安装依赖或部署，不承诺任意语言/复杂系统均可直接运行或生产可用。

本版不修改导入仓库、不自动创建Git提交，不允许模型任意Shell或SQL。用户可选择仅验证，或失败后最多 1～2 次 AI 修复并复验；修复不得删改原测试、依赖或数据文件，结果保存为独立版本。继续修改时先提出要求、核对修改计划，再显式确认生成新版；可以比较文件差异和选用旧版本。失败与取消保留此前成功源码，原确认方案不原地改写。

### 真实浏览器与模型验收

2026-11-13，使用本地MySQL、当前账户COMPATIBLE连接及gpt-6.1-sol模型，实际创建“个人待办小工具”样例。初始理解与4次追问分别约27.1、28.2、33.3、31.2、29.5秒，共保存5个版本、8项选择：

- 先确认命令行、本机使用，再提供Python、TypeScript、Go语言选项，没有预设Java。
- 采用Python后继续选择标准库argparse、少量模块简单分层、本地JSON文件、源码运行和unittest加手动验收；最终方案保留这些决策，明确不加入登录、网络和数据库服务。
- 确认HTTP 200；源码任务约20毫秒返回HTTP 202，约2分钟后页面显示SUCCEEDED。生成7个模型文件和1个宿主检查记录，包括main.py、tasks.py、storage.py、data/tasks.json、requirements.txt、tests/test_todo.py、README.md、DEVMATE_GENERATION.md。

## 生成后的五步增强（2026-11-14）

- 每个版本可生成用途、模块、业务流程和阅读顺序；文件引用必须存在于该版本清单。已保存导览读取不调用模型，更新需显式提交。
- 运行向导根据实际文件显示环境、配置、启动和测试步骤，不检测用户电脑、不自动执行命令。报错解释在常见凭据模式脱敏后发送当前模型，用户仍应先删除秘密。
- GENERATE / VERIFY / PLAN / CHANGE / GUIDE / ERROR_HELP 记录真实阶段、排队/开始/结束时间、模型调用次数与返回的 Token。上游未给完整用量时显示未知，不估算费用。
- 后台任务可以取消；取消与发布使用同一数据库行锁，取消后不能发布晚到结果。排队取消不调用模型，已发出的请求仍可能计费。失败/取消后的新尝试由用户显式触发。
- 初始生成任务仍可通过原文件与ZIP接口读取；扩展版本采用独立目录、独立列表与选用指针，不覆盖导入仓库。

### 配置隔离验证

默认关闭。管理员需准备 Docker 和固定官方镜像，运行期间不拉取镜像。可在专用 Docker context 中预装：

```sh
docker --context colima-ragent pull python:3.13.2-alpine3.21
docker --context colima-ragent pull node:22.14.0-alpine3.21
docker --context colima-ragent pull eclipse-temurin:21.0.6_7-jdk-alpine
DEVMATE_GENERATION_SANDBOX_ENABLED=true \
DEVMATE_GENERATION_SANDBOX_DOCKER_CONTEXT=colima-ragent \
./scripts/start-local.sh
```

将 context 改成自己的名称；未设置时为 default。固定容器无网络、无宿主目录挂载、非 root、只读根目录、限时 90 秒、512MB 内存、1 CPU、64 PID 和截断输出。模型不能选择镜像或任意 Shell 命令。此隔离是学习项目的受限验证环境，不等于生产部署。
