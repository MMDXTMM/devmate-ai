# 生成项目的五步增强（2026-11-14）

## 顺序与回归门禁

每一项独立实现并执行后端全量测试、前端全量测试、生产构建、差异检查，再进入下一项。保留既有导览、聊天、审查与生成入口，新增能力只作用于已生成项目。

1. 隔离验证与有限修复：原始源码只读快照；固定白名单运行器，Docker无网络、非root、资源/时间/输出限制，无宿主挂载/秘密。Python标准库、Node原生JS测试、Java无外部依赖源码可执行；依赖或不支持栈明确BLOCKED。最多2次AI修复，原测试及依赖配置不得删改，结果形成独立版本。
2. 持续修改与版本：基于指定成功版本，先生成修改计划，用户核对后生成新版本；查看新增/修改/删除与文本差异，可恢复旧版本。初始源码与旧版本保留，失败不切换当前版本。
3. 生成与理解衔接：从准确的源码快照生成用途/模块/流程/阅读路径，引用现存文件，缓存到对应版本，显式付费刷新。
4. 新人运行向导：宿主识别文件及所需环境，逐步显示准备/配置/启动/验证；用户可提交脱敏报错，AI只解释和建议，不执行命令。
5. 等待与费用反馈：真实任务阶段、开始与耗时，记录模型返回的Token（未知不伪造），显式取消，状态CAS禁止取消后发布结果，不自动付费重试。

## 数据与接口边界

保留generation_run及V27契约。增量generation_revision快照用于原版/修复版/修改版，唯一run_id+attempt_key保证幂等，独立存储目录与清单；generation_verification绑定准确版本及验证配置，保存状态、固定命令、退出码、截断输出与修复链。原生成文件/ZIP仍可读。所有操作从父会话验证归属，ID为字符串。模型调用和执行不包围数据库长事务。

状态：版本RUNNING→SUCCEEDED/FAILED/CANCELLED；验证RUNNING→PASSED/FAILED/BLOCKED/CANCELLED；不可运行或无测试不得显示测试通过。受控子进程仅用于容器固定命令，不接受模型Shell、SQL、镜像或参数。
