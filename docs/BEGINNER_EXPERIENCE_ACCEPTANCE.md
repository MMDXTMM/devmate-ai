## 本轮边界与契约

沿用 Java + Vue 模块化单体、MySQL 和现有导入快照；被分析项目不限 Java。保留历史报告、会话、权限、幂等、SSE 及取消。不自动调用付费模型；首次及更新必须由用户显式触发。读取失败不转为生成。所有证据固定项目和 revision。

通用拆解 Skill 负责侦察、证据核对与分层解释，产品负责工具权限、预算、数据与可观察状态。未知语言降级为文本，不伪造语法解析、运行结果或调用链。

## 论文表达

以“跨语言项目通俗理解与证据溯源”为可验证方法：输入为授权固定快照，经过项目识别、运行源码优先取样、证据约束生成，再以三层导览和版本化问答呈现。区分静态观察、测试预期与运行验收。

实验分别报告样本、版本、问题、目标证据、命中排名、任务状态、耗时和限制；对照同一问题与快照。不得用两份样例推断所有项目准确，也不把 Mock 测试当模型效果、性能或教学成绩。
